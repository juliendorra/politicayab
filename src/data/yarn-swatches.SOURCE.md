# Nuancier de fils à tricoter

Nuancier issu de [Temperature Blanket](https://temperature-blanket.com/api/yarn-colorways),
sous licence [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Les codes hexadécimaux sont des approximations pour l’écran.

Le fichier `yarn-swatches.tsv` contient 14 172 teintes de 82 marques,
extraites de la [révision c7a9ba7 du catalogue](https://github.com/jdvlpr/Temperature-Blanket-Web-App/tree/c7a9ba7f2117df884837711e6fb66657f1cf9df3/src/lib/data/yarns).
Nous avons gardé le code hexadécimal, le nom du coloris, la marque et la gamme,
mis les codes en minuscules et retiré les références de fil à crocheter de
catégorie `t` et les sources signalées comme indisponibles dans le catalogue.
